# Homelab Repository Instructions

This repository documents my personal homelab for public technical use.
Keep the writing concrete, concise, and understandable to someone seeing the
project for the first time.

Use real technology names, hardware roles, engineering decisions, and dated
snapshots when they are safe to publish. Prefer direct factual sentences over
promotional language, rhetorical contrast ("not X, but Y"), inflated phrasing,
or repeated process disclaimers. Use first person sparingly, mainly in the
README. Use em dashes sparingly.

Do not publish secrets, credentials, keys, recovery material, private addresses
or DNS names, public IPs, serial numbers, exact management endpoints,
secret/config locations, sensitive backup identifiers, or executable recovery
procedures. Dated snapshots are historical. Verify live state before making a
freshness-sensitive claim.

Repository state and documentation do not grant permission to access or change
live systems, deploy, publish, or write externally. Preserve unrelated changes
and stop for owner approval at consequential boundaries.
