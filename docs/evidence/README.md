# Selected dated engineering evidence

This directory preserves a small set of public-safe records that are useful for
understanding how the Homelab was actually changed or verified.

Evidence is deliberately **dated**. A successful observation on one date is not
a claim about current runtime health, inventory, exposure, or recovery
readiness.

The June records were adapted from earlier Sahale engineering history during the
Homelab extraction. The September baseline is Homelab-owned evidence gathered
after that separation.

Records omit private addressing, private DNS, host/guest identifiers, exact
inventory, secret locations, credentials, executable runbooks, and other detail
that is not necessary to preserve the engineering result.
